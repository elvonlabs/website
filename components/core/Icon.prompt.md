**Icon** — the Elvon outline icon set; single-color, inherits `currentColor`. Use for research-domain glyphs, list checks, and CTA arrows.

```jsx
<Icon name="ai" size={28} style={{ color: 'var(--blue-400)' }} />
```

Names: `ai`, `healthcare`, `quantum`, `telecom`, `cs`, `robotics`, `book`, `check`, `cube` (logo mark), `arrow`. Size via `size`; color via the parent's text color or inline `color`.
