**Button** — friendly pill CTA. `primary` (indigo) for the main action, `secondary` (coral) for a warm alternate, `soft` (indigo tint) for low-emphasis, `ghost` (outline) for tertiary. Gentle lift on hover.

```jsx
<Button variant="primary" size="lg">Apply now</Button>
<Button variant="secondary">Start with a Foundations Pod</Button>
<Button variant="soft">Learn more</Button>
<Button variant="ghost">See the curriculum</Button>
```

Props: `variant`, `size` (sm/md/lg), `full`. Pair with `<Icon name="arrow" />` for a trailing arrow.
